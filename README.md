# CutieWorld — Forge 1.20.1

Cute functional world content:
- Woodland Workshop: crafting table, chest, campfire, flower pots and a Nutkin companion.
- Moonbloom creatures: cute mobs that can be sheared for Moonbloom Petals.
- Cloudberry / Acorn items prepared for expansion.

## Build
Java 17 + Forge 1.20.1.
GitHub Actions automatically builds the JAR and uploads it as an artifact.
